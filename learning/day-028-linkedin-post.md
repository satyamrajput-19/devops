🚀 Day 28 — Kubernetes Introduction | DevOps & Cloud Engineering

Today I began learning Kubernetes and container orchestration, moving from managing individual containers to understanding how applications run inside a cluster.

🔹 Kubernetes cluster and control-plane architecture
🔹 Worker nodes and Pods
🔹 Services and stable networking
🔹 kubectl for inspecting and managing resources
🔹 Minikube for a local Kubernetes lab
🔹 Deploying an Nginx Pod and exposing it with a ClusterIP Service
🔹 Troubleshooting with describe, logs, and events

Key takeaway: Pods run workloads, while Services provide a stable way to reach matching Pods. Kubernetes declarative manifests help describe the desired state of resources.
