🛠️ Day 26 — Getting Started with Ansible | DevOps & Cloud Engineering

Today I started learning Ansible for configuration management and repeatable server automation.

🔹 Configuration management and push vs. pull models
🔹 Ansible control node, managed hosts, and inventory
🔹 Ad-hoc commands for connectivity and system information
🔹 Playbooks, variables, facts, roles, and collections
🔹 Idempotency: describing the desired state instead of repeating manual commands
🔹 Safe previews with check mode and diff
🔹 SSH access, privilege escalation, and troubleshooting

Key takeaway: reliable automation should be repeatable, understandable, and safe. Idempotent playbooks help bring systems to a desired state while reducing unnecessary changes.
